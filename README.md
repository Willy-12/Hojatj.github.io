## 🎯 Acerca del Proyecto

Este proyecto contiene la interfaz web y la plantilla interactiva para la emisión de **Órdenes de Servicio todo listo para imprimirse o exportarse en un formato limpio de una sola hoja A4.


## 🛠️ Tecnologías Utilizadas

- **HTML5 & CSS3:** Estructura semántica y estilos avanzados optimizados para impresión (`@media print`).
- **JavaScript:** Interactividad en el cliente (limpieza de formularios y control de exportación).
- **Librerías de Exportación:** Soporte para renderizado y conversión a PDF (`html2pdf.js`).

## 🚀 Uso e Instalación

No se requiere un servidor complejo ni instalación de dependencias de Node.js para probar la interfaz localmente:

1. **Clona o descarga el repositorio:**
   ```bash
   git clone https://github.com/tu-usuario/tjinformatica-servicio-tecnico.git
   ```
2. **Abre el archivo:**
   Haz doble clic en el archivo `Index.html` para abrirlo en cualquier navegador web moderno (Google Chrome, Microsoft Edge, Firefox).

---

## 📄 Exportación a PDF

1. Completa los campos necesarios directamente en la interfaz web.
2. Haz clic en el botón superior **"📄 Exportar PDF"**.
3. Se generará automáticamente el archivo `Orden_Servicio_TJInformatica.pdf` listo para ser guardado o impreso.
